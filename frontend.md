# Frontend development

Before building any frontend functionality, inspect the Multica app at `~/projects/multica` for its established styles, design tokens, components, UI patterns, and implementation conventions.

Use Multica as the primary source of truth. Before creating a new component, first look for an equivalent there and, where appropriate, copy or port it completely. Only create a new component when Multica has no suitable equivalent; keep any new work consistent with its visual language and conventions.
